🕷️ WebTab

your new tab page but it actually has main character energy. built this because staring at a blank tab every time i opened the browser got mad boring.

live: https://Dxkshh-Codee.github.io/WebTab/

what it actually does
a tiny spider follows your cursor around the whole page, no reason, it just does
there's a glowy web in the background that stretches out toward your mouse the closer you get
spider hanging off the search bar runs away if you click it, then quietly comes back like nothing happened
"spidey-sense" box drops a random quote on you, and if the api flops it just gives you a backup one so it never looks broken
click literally anywhere and it shoots a lil web trail from the middle of the screen to your cursor
greeting text and the clock change depending on what time it actually is, so it knows if you're up way too late

no frameworks, no bloat, just html css js doing the most.

built this mostly to actually get fetch, canvas, and animations to click instead of just reading about them and nodding. still poking at it here and there, lmk if something's acting up.
